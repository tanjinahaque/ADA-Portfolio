# Archived articles and portfolio reference

The active portfolio no longer contains the Articles navigation, listing, or child pages.
The reusable source is preserved in `articles-for-future-project.zip` in this directory.

## Contents

- `articles.html`: full article listing.
- Nine `article-*.html` pages: complete article text, markup, and inline JavaScript.
- `articles-section.html`: original homepage article cards and navigation destination.
- `style.css`: original complete stylesheet, including article styles, shared components, and responsive rules.
- `index.html`: original purple homepage, with the Articles section intact.
- `image/`: original portfolio image assets.
- `case-study-*.html` and `skill-details.html`: supporting examples for future project work and the original homepage destinations.

## Reuse

Extract the ZIP into a separate project directory and open `articles.html`, or serve that directory with your local development server. Keep the file structure intact so relative links and styles resolve. The original password gate and scripts are preserved; Google Fonts requires internet access.

Use the article pages as writing/layout templates, the original homepage for section structure, and the case studies for project presentation patterns. Review historical content and outcome claims before reusing them in a new project.

The ZIP is reference source, not an active HTML route. Keep the archive out of deployment uploads if it should not be downloadable. The earlier purple portfolio is also preserved by Git tag `last-purple-portfolio-change`.
